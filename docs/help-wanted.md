# Help wanted

You can make a useful contribution without knowing every part of Blender.

| Experience | Useful first contribution | Evidence to include |
| --- | --- | --- |
| Blender artist | Run a few steps in the interactive checklist | Build, mode/editor, steps and observed result |
| Maya artist | Compare one specific action with its Blender equivalent | Public reference, expected gesture and exact difference |
| Python developer | Fix one keymap conflict or registration regression | Focused patch, cold-start check and regression test |
| Rigger or animator | Review a shelf action or playback/keying workflow | Small synthetic example and suggested behavior |
| UI designer | Improve panel hierarchy or readable control labels | Mockup and explanation of the artist task |
| Documentation contributor | Clarify installation, recovery or one shortcut | Tested instructions and target platform |

Start with [CONTRIBUTING.md](../CONTRIBUTING.md), the [roadmap](../ROADMAP.md) and [testing checklist](testing.md). Open a focused issue for a task you want to tackle. Maintainers can label suitable issues `good first issue` or `help wanted`; those labels do not imply that work is assigned or complete.

Please share original work, public references and synthetic test scenes. Do not contribute Autodesk manuals/source or someone else's project files.
