# Shortcuts

These are the current mappings in the Baya 3D key configuration. Use them with the pointer over the 3D viewport and no text field in edit mode. Mode-specific tools require a compatible active object. Other editors retain their own controls, and unmapped actions inherit Blender's Industry Compatible keymap.

| Key or gesture | Action |
| --- | --- |
| Alt + left/middle/right mouse drag | Orbit / pan / dolly |
| Q / W / E / R | Select / Move / Rotate / Scale tool |
| T | Universal transform manipulator (`builtin.transform`) |
| Y | Recall last modeling tool other than Select/Move/Rotate/Scale |
| G | Repeat last operation |
| F / A | Frame selected / frame all |
| Hold X / C / V | Snap to Grid (`X`), Curve/Edge (`C`), or Point/Vertex (`V`) while held |
| D or Insert | Toggle Edit Pivot mode |
| B | Toggle Soft Selection (Proportional Editing) |
| Ctrl + D | Duplicate selected objects in place |
| Ctrl + G | Group selected objects under a new `group1` transform node |
| P / Shift + P | Parent / unparent |
| Ctrl + Z / Ctrl + Y | Undo / redo |
| Ctrl + N / O / S / Shift+S | New / open / save / save as |
| 1 / 2 / 3 | Base mesh / cage + smooth preview / smooth preview |
| Page Up / Page Down | Raise / lower visible smooth preview subdivisions |
| 4 / 5 / 6 / 7 | Wireframe / smooth shaded / material preview / rendered scene lighting |
| F8 | Toggle object and component mode |
| F9 / F10 / F11 / F12 | Vertex / edge / face / UV selection |
| Ctrl + F9 / F10 / F11 | Convert selection to vertices / edges / faces |
| F2 / F3 / F4 / F5 / F6 | Switch Modeling / Rigging / Animation / FX / Rendering Menu Set & Shelf |
| Right mouse (RMB) | Component & Object Marking Menu (with Pivot actions when in `D` Pivot Mode) |
| Shift + Right mouse | Context-sensitive Polygon Tool Marking Menu (Object / Vertex / Edge / Face) |
| Ctrl + Right mouse | Selection Conversion & Loop/Ring/Grow/Shrink Marking Menu |
| Tap Space | Toggle Single / Four-View layout |
| Hold Space | Maya Hotbox pie menu |
| Ctrl + E / Ctrl + B | Extrude / Bevel |
| Ctrl + Delete / Backspace | Delete Edge / Vertex (dissolve edges and orphaned vertices) |
| S | Insert location, rotation and scale keys |
| Shift + W / E / R | Insert location / rotation / scale keys |
| Alt + V | Play / pause |
| Alt + comma / period | Previous / next frame |
| Comma / period | Previous / next keyframe |
| Hold K + middle mouse drag | Scrub timeline |
| Ctrl + A | Toggle Right Dock (Channel Box / Modeling Toolkit / Attribute Editor) |
| Ctrl + 1 | Isolate Select toggle |
| Ctrl + H / Shift + H | Hide selected / Show hidden objects |
| Ctrl + Shift + A / Ctrl + I | Select all / invert selection |
| Tab | Search all commands |

See [limitations](limitations.md) for engine differences and [testing checklist](testing.md) to verify behavior.
